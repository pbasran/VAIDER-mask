VAIDER-mask

A veterinary DICOM anonymizer. It removes owner, patient and clinic identifiers from CT, MR and radiotherapy files, and keeps the key in a separate restricted folder.

Download (zip)View on GitHub

Draft v0.3. Not validated on real data. Tested on synthetic CT and RTSTRUCT only. Test on phantom or synthetic data first, have a second person check the output, and follow your institution's rules before sharing any data. It does not remove text burned into image pixels. Provided as is, with no warranty.

Why it runs on your computer

Patient files should not be uploaded to a website. VAIDER-mask runs a small page from your own computer only (127.0.0.1). It makes no network calls after the first setup, sends no telemetry and uses no AI.

Get started

  1. Install Python 3 if you don't have it.
  2. Click Download (zip) above and unzip it somewhere outside any cloud-synced folder.
  3. Mac: double-click START_Mac.command (if it is blocked, right-click and choose Open). Windows: double-click START_Windows.bat.
  4. The first run sets up its own Python environment and installs pydicom and numpy. This needs internet once. A page opens in your browser.
  5. Try it on synthetic data first: python3 scripts/make_test_data.py my_test_folder

What it does

One folder per scan set

Understands Pinnacle exports; skips duplicate ImageSet copies and keeps structure sets matched to their images.

Stable new IDs

Assigned once, saved in the key and reused in later batches. Each site numbers its own patients.

Safe redaction

Whole-word matching only; structure names are never changed. Dates shift per animal; UIDs are remapped consistently.

Checks after writing

Reads the output back for leftover identifying text, changed pixels and broken references.

CE / No CE per set

Records contrast status for each scan set, plus species, region and orientation.

Key kept apart

The crosswalk and audit report go to a restricted folder, never into the shareable data.
