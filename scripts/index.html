1. Source (data to de-identify)

A folder is searched through all subfolders. Patients are grouped by PatientID. Non-DICOM files are skipped.

2. Output folder

Creates DEID_DATA here (shareable after review): <NewID>/set_NN/CT/…, plus deid_sets.csv (one row per scan set), deid_index.csv (one row per file) and run_report.json. None of these contain original names.

3. Crosswalk (links new IDs back to real animals)

Restricted. The crosswalk identifies the animals and clients. It holds the key, set map, and anonymization_report.csv (original folder names). By default it sits beside DEID_DATA, not inside it. Never share, analyse from, or commit the whole output folder. Share DEID_DATA only. Better: choose a separate restricted folder above. Reuse the same crosswalk folder for later batches: each patient keeps the ID first assigned, and each site numbers its own patients (Site 2 starts at Z002001).
